# Training a Neural Network in Pure HTML and CSS

[Live demo](https://html-css-cnn-demo.netlify.app/)

A tiny convolutional neural network learns to distinguish 8×8 X and O glyphs. Press **Start** once to run training automatically. The browser computes the forward pass, cross-entropy loss, backpropagation, and quantized SGD updates with HTML and CSS. The standalone page contains no JavaScript.

The architecture is `8×8 → two shared 3×3 convolution filters → ReLU → 2×2 max pooling → 18-to-2 dense layer → softmax`. Its 58 trainable parameters live in two banks of CSS animation registers. View timelines read the values back, and a commit timer advances after writes finish. The dashboard shows predictions, parameter updates, a sampled loss curve, and accuracy on training and held-out glyphs.

## Run

Open `site/index.html` in a supported browser, or use the live demo. The recorded tests used Chromium 153 and WebKit 26.6. Firefox 155 did not support the required CSS features. Reloading resets learned values; long background stalls can skip training steps.

## Generate the page

The checked-in HTML is ready to run. Python is only an offline generator and numerical reference; it is not a runtime dependency.

```sh
python3 tools/auto/gen_auto.py
```

This regenerates `site/index.html`. The presentation is defined in `tools/auto/new_html.py`; network arithmetic and register rules are generated by `tools/auto/gen_auto.py`. The reference network and glyph dataset are in `tools/cssfull/ref.py`.

## Verify training

The prior browser checks compared 288 successive updates and sampled loss history against the numerical reference in both Chromium and WebKit. Later copy and spacing changes preserved the computational CSS. To run checks yourself:

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/playwright install chromium webkit
.venv/bin/python tools/auto/test_curves.py chromium 24
.venv/bin/python tools/auto/test_curves.py webkit 24
.venv/bin/python tools/auto/test_handsoff_curves.py chromium 30
```

The final command disables page JavaScript, clicks Start once, waits without interacting, then compares the resulting weights and loss samples to the reference. The verification harness itself uses Python and browser automation; the demo computation stays in CSS.

## Deploy

`netlify.toml` publishes only `site/`. No build command is needed because the generated page is checked in. Disable Netlify's “Powered by Netlify” badge for this project to avoid host-injected JavaScript.
